# Spec Delta

## MODIFIED Requirements

### Requirement: Главная страница выводит только приветствие
Главная страница по пути `/` SHALL выводить элемент `<div>` с текстом `Hi` и кнопку «Выйти», которая отправляет `POST /api/auth/logout`. Другого видимого контента страница SHALL NOT содержать.

#### Scenario: Открытие корневого пути
- **WHEN** пользователь открывает `/`
- **THEN** страница возвращается со статусом 200
- **AND** в `<body>` отображаются `<div>Hi</div>` и кнопка «Выйти» (не считая служебных скриптов)

#### Scenario: Нет шаблонного контента
- **WHEN** пользователь открывает `/`
- **THEN** на странице нет логотипа React Router, текста «What's next?» и ссылок на документацию или Discord

#### Scenario: Нажатие «Выйти»
- **WHEN** пользователь нажимает «Выйти»
- **THEN** браузер отправляет `POST /api/auth/logout` и оказывается на `/login`
