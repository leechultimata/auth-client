# Spec Delta

## Purpose

Определяет защищённую страницу личного кабинета `/profile`, доступную только авторизованному пользователю.

## ADDED Requirements

### Requirement: Личный кабинет для авторизованного пользователя
Если запрос к `/profile` содержит cookie `accessToken`, а внешний сервис `GET {AUTH_API_URL}/me` с заголовком `Authorization: Bearer <accessToken>` отвечает `200`, страница SHALL отвечать статусом 200 и выводить `<div>Личный кабинет</div>`.

#### Scenario: Вошедший пользователь открывает кабинет
- **WHEN** пользователь после входа `test`/`test` открывает `/profile`
- **THEN** страница отвечает 200
- **AND** в `<body>` отображается `<div>Личный кабинет</div>`

### Requirement: Перенаправление неавторизованного пользователя
Если cookie `accessToken` нет, сервис ответил не `200` или недоступен, запрос к `/profile` SHALL перенаправляться на `/login`, а содержимое кабинета SHALL NOT отдаваться.

#### Scenario: Нет cookie
- **WHEN** пользователь без cookie `accessToken` открывает `/profile`
- **THEN** ответ — редирект на `/login`

#### Scenario: Недействительный токен
- **WHEN** cookie `accessToken` содержит поддельный или истёкший токен
- **THEN** ответ — редирект на `/login`

#### Scenario: Сервис авторизации недоступен
- **WHEN** пользователь с cookie `accessToken` открывает `/profile`, а сервис недоступен
- **THEN** ответ — редирект на `/login`

#### Scenario: После выхода
- **WHEN** пользователь нажал «Выйти», а затем открыл `/profile`
- **THEN** ответ — редирект на `/login`
